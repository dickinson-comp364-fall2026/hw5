# Fact-learning transformer 

In this assignment, the objective is to train a transformer model to learn elementary facts from a knowledge base. The transformer will demonstrate its knowledge by correctly completing partial statements from the knowledge base. We'll call this a _fact-learning transformer_.

The _knowledge base_ consists of a set of simple statements about the properties of a few common objects. For example, the knowledge base may contain the following statements:
```
The coin is circular.  
The book is blue.  
The coin is metal.
```
The knowledge base is just a stream of characters employed to train the transformer. Therefore, we also refer to the knowledge base as the _training stream_. We will use the terms knowledge base and training stream interchangeably. 

After learning the knowledge base, or training on the training stream (these are two ways of saying the same thing), the transformer should be able to complete partial statements. For example, if the transformer is given the partial statement:
```
The coin is
```
it should complete the statement with a correct property of the coin, such as:
``` 
circular.
``` 
or
``` 
metal.
```

Because transformers are probabilistic models, we can also ask for the probabilities of the most likely tokens to be generated by a given prompt. This allows us to assess the confidence and correctness of the transformer's predictions. For example, if the transformer is given the prompt:
```
The coin is
```
it may return the following probabilities for the next token:
```
 1. id=15     prob=0.406076 ( 40.61%) token='circular'
 2. id=31     prob=0.235819 ( 23.58%) token='small'
 3. id=27     prob=0.210534 ( 21.05%) token='metal'
 4. id=6      prob=0.030000 (  3.00%) token='black'
 5. id=19     prob=0.027166 (  2.72%) token='glass'
 6. id=22     prob=0.011651 (  1.17%) token='is'
 7. id=18     prob=0.009874 (  0.99%) token='cylindrical'
 8. id=14     prob=0.009263 (  0.93%) token='cardboard'
 9. id=2      prob=0.005189 (  0.52%) token='\n'
10. id=20     prob=0.004826 (  0.48%) token='green'
```
We can interpret this as saying that, given the knowledge base, the transformer is reasonably confident that a coin:
- _should_ be circular, small, and metal;
- _should not_ be black, glass, cylindrical, cardboard, or green.

The remainder of this document leads you through the toolchain for building the knowledge base and training the transformer.

# Tool chain for fact-learning transformers

## 1. Create the training stream/knowledge base
```bash
py create_data.py --stream-byte-target 1024
```
Output:
```
Generated stream with 49 sentences and 1039 bytes
Seed: 1234
Saved to project-root\data\stream.txt
```
As mentioned above, we refer to the `stream.txt` file as the _training stream_ or _knowledge base_. It begins with something like:
```
The scarf is rectangular.
The coin is circular.
The cup is cylindrical.
```

## 2. Train a tokenizer for the training stream.
```bash
cd tokenization/
py train_tokenizer.py --tokenizer-type simple_words
```
Output:
```
Tokenizer trained.
Input: project-root\data\stream.txt
Tokenizer type: simplewords
Configured vocab size: 35
Artifacts written to: project-root\tokenization\artifacts\simple_words
Files: vocab.json, tokenizer.json, sample_encoding.txt
```
The training stream has been tokenized into a vocabulary of 35 tokens, so that each word in the stream is represented by a unique integer ID. The tokenizer artifacts are saved in the `tokenization/artifacts/simple_words` directory. Take a look at each of the three files generated in that directory. The `vocab.json` file contains the mapping of each token to its integer ID. The `tokenizer.json` file contains the configuration for the tokenizer. The `sample_encoding.txt` file shows a sample encoding of the training stream into token IDs.


## 3. Encode the data stream into token IDs.
```bash
py encode_stream_ids.py --tokenizer-type simple_words
```

Output:
```
Continuous stream encoding complete.
Input text file: project-root\data\stream.txt
Tokenizer type: simple_words
Token count: 441
Dtype: uint16
Wrote: project-root\tokenization\encoded\simple_words\stream_ids.bin
Wrote: project-root\tokenization\encoded\simple_words\stream_ids_meta.json
Wrote: project-root\tokenization\encoded\simple_words\sanity_check.txt
```
The encoded token IDs are saved in the `stream_ids.bin` file, along with metadata in `stream_ids_meta.json` and a sanity check in `sanity_check.txt`. The `stream_ids.bin` file is stored in a binary format. It is easy for a PyTorch model to import but we cannot easily inspect directly. However, you should examine the other two files to understand their content.
